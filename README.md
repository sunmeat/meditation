# Тихо поруч 🌙

**Одна хвилина опори, коли навколо неспокійно.**

Україномовний безкоштовний вебпростір для короткої паузи під час стресу, виснаження та невизначеності. Натхнено мінімалістичними медитативними вправами на кшталт Pixel Thoughts, але з власною візуальною мовою та текстами, що враховують реальність життя під час війни в Україні.

> **Безпека понад усе.** Сайт не перевіряє повітряні тривоги. Під час загрози спершу прямуйте до укриття та дотримуйтеся офіційних вказівок. Вправа не замінює психологічну або медичну допомогу.

## Як працює

1. За бажанням напишіть одну думку, яка турбує. Можна й нічого не писати.
2. Запустіть 60-секундну вправу.
3. Разом зі стартом вправи починає звучати локальний трек `public/1.mp3`. Музику можна вимкнути під час вправи.
4. Спостерігайте, як велика світлова точка поступово віддаляється, а зорі повільно рухаються, читайте короткі фрази та помічайте опору навколо.
5. У будь-який момент можна призупинити або зупинити вправу. Музика зупиняється разом із таймером, але позиція треку зберігається до наступної хвилини.

## Технології

- Vite + TypeScript, без серверної частини;
- адаптивний інтерфейс для телефонів, планшетів і комп’ютерів; повага до системного налаштування зменшеного руху;
- без аналітики, кукі, реєстрації, завантаження думок на сервер;
- PWA: після першого завантаження може працювати офлайн; музика може бути недоступна без мережі, якщо браузер не зберіг повний MP3;
- трек користувача `public/1.mp3`, без сторонніх потокових сервісів; наприкінці хвилини музика плавно згасає, а наступна хвилина продовжується з того самого місця та з плавним збільшенням гучності;
- українська мова всюди.

## Запуск

```bash
npm install
npm run dev
```

Виробнича збірка:

```bash
npm run build
npm run preview
```

Для розгортання на Vercel / Netlify використовуйте команду збірки `npm run build` і каталог `dist`.

## Принципи

- Ніяких імітацій повітряних тривог, вибухів чи сирен.
- Не обіцяємо безпеку чи швидке зникнення страху.
- Усі функції доступні без звуку.
- Без гендерних припущень і вимог «заспокоїтися».
- Введений текст залишається у вкладці та зникає після перезавантаження.
